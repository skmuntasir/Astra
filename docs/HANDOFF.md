# HANDOFF — protocol and rules for every prompt

Written generally: it applies to Prompt 2 and every prompt after it.

## Protocol

1. **Read first:** `docs/BRIEF.md` (the spec, immutable), `docs/STATUS.md` (where we are), `docs/ASSETS.md` (what images exist and where they come from), then this file.
2. **Work only inside your lane.** A prompt that adds a zone adds files under `src/zones/` and registers them in `src/zones/index.ts`. It does not edit `src/engine/`. If the engine genuinely cannot do something, make the smallest engine change, write it in STATUS.md under "Engine changes", and keep the old behaviour working.
3. **Finish green:** `npm run typecheck`, `npm run build`, `npx tsx tests/path.test.ts`, `npx tsx tests/ephemeris.test.ts`, and the browser suite (`npm run build && npx vite preview --port 4173 &` then `npm run test`, which runs `tests/e2e.py`) must pass. Do not weaken a test to make it pass; fix the cause or record the limitation.
4. **Update STATUS.md** (what exists, what is verified, what is known-bad) and **ASSETS.md** (via `npm run textures`, never by hand) before you finish.
5. **Be honest.** If something looks synthetic, is unverified, or was skipped, say so in STATUS.md and in the final message.
6. The final message is short. Deliver a zip (no `node_modules`, `dist`, `.git`) that includes `public/textures`.

## Rules (hard)

- **One Canvas, mounted once** (`src/engine/Engine.tsx`). Never unmount it, never create a second one.
- **Objects are never unmounted or disposed.** They are mounted once after the preloader's fetch stage, and the Driver toggles `visible`. Inactive-zone objects are `visible=false`.
- **Everything is loaded before the journey starts.** New texture/model = new row in `src/engine/assets.ts` (`ASSETS`). The preloader fetches (byte-accurate progress), decodes, uploads (`initTexture`), compiles shaders and renders a warm-up frame per zone. Nothing may be lazy-loaded during the journey. (Credits-page-only files are `preload:false`.)
- **Texture budget:** desktop ≤ 60 MB total, mobile tier ≤ 2k per map. `npm run check:budget` enforces it. Provide a `lo` file for anything above 2k.
- **Floating origin.** The THREE camera never leaves the render origin. Author positions in **global metres (doubles)** via `registerObject({position, radius})`; the Driver places objects at `(position − cameraPos) × k`. Components draw a **unit-radius** body at their local origin. Never put a world-space metre value into a shader or geometry.
- **Logarithmic depth is on.** Any custom `ShaderMaterial` must include `<logdepthbuf_pars_vertex>/<logdepthbuf_vertex>` and `<logdepthbuf_pars_fragment>/<logdepthbuf_fragment>` (see `src/zones/Earth.tsx`) and end with `<colorspace_fragment>`. Without them it z-fights or clips.
- **Zone joins must be continuous.** The last camera key of a zone equals the first of the next (position, distance, angles). `tests/path.test.ts` checks this. Use `hold: true` for a deliberate pause; never a cut.
- **No cuts.** Far jumps (rail) use the cross-fade curtain; everything else flies.
- **Speculative content is labelled** (the multiverse zone: "speculative", on screen).
- **Images:** procedural images are generated by `tools/texgen` (deterministic seeds, idempotent) and labelled `procedural`. Never download an image. The one allowed network attempt has already been made and failed (ASSETS.md); do not retry.
- **Not part of the product:** the old Observatory, Star Map, Deep Space, Search for Life, Humanity, Stars, Milky Way, Galaxies, Universe and Cosmic Scale chapters, and anything about habitable planets.
- **Dependencies:** Vite 6, React 19, TypeScript, three, @react-three/fiber, Tailwind 4, lenis, zustand; `sharp` (dev, texture generator only), `tsx` (dev, runs the generator). **Nothing else without a written reason below.**

## How to add a zone (Prompt 2+)

```ts
// src/zones/sun.ts  (import it from src/zones/index.ts)
registerObject({ id: 'sun', name: 'Sun', position: [1.496e11, 0, 0], radius: 6.957e8, Component: SunBody, focus: { distRadii: 3 } })
registerZone({
  id: 'sun', title: 'The Sun', tick: 'Sun', budget: 200, unit: 6.957e8 /* metres per zone unit */,
  scale: 'Star scale', objects: ['sun'],
  camera: [ { t: 0, target: [...], dist: ..., azim: ..., elev: ... } /* == previous zone's last key */, { t: 1, ... } ],
  beats: [ { id, title, body, w: [inStart, inEnd, outStart, outEnd] } ],
})
```
Order of `registerZone` calls = order of the journey. Ranges re-flow from budgets automatically.

## Hooks

- `focus(objectId)` / `release()` — `src/engine/api.ts`. Freezes the timeline and scroll, flies to `radius × distRadii`, shows the info panel (`info` on the object). `release()` flies back and restores the exact saved `t` and scroll position. Use for clickable planets: call `focus(id)` from the object's `onClick`.
- `choiceGate.open({ id, title, prompt, options: [{ id, label, branch? , gotoT? }] })` — overlay; scroll and camera are paused until a choice. `branch` enters a sub-timeline registered with `registerBranch(id, zones)`; the branch scrolls on its own page height, its first camera key is blended in over 1.6 s, and at its end (or via `exitBranch()`) the page returns to the exact main scroll position.
- `jumpToZone(i)` — adjacent = fly, otherwise cross-fade.
- `window.__astra` — debug/test handle (state, scrollToT, hooks). Do not use it from app code.

## Test tools

- `?test=scale` — scale test flight (`window.__scaleTest()`), 1 → 1e10 Earth radii.
- `?test=planets` — the procedural planets on spheres, to eyeball maps and normal-map orientation.

## Prompt 5 additions (galactic zones)
- All of it is in `src/zones/galactic/`, registered by `registerGalactic()` (called from `src/zones/index.ts` after `registerSolar`). Each zone's first key is COPIED from the previous zone's last key (`lastKeyOf`), so joins are exact; keep doing that.
- Objects: `gx-near`, `gx-mw`, `gx-fx` (origin = Sun, unit 1 ly), `gx-virgo` (origin = M87, unit 1 Mly), one object per galaxy (`gx-m31`...) and `gx-m87`. Zone `objects` lists are deliberately the UNION so nothing pops when a zone window opens; per-galaxy distance gates (`gx.sunLy`) do the fading.
- Sprites: one shader (`spriteVert/Frag`), size = max(px, light-year size projected) clamped; flux is conserved with a `dim` factor as a layer shrinks. Picture planes: `quadVert/Frag`, additive, fade when edge-on.
- Precision rule: put each object's origin at its own centre (a Virgo/M87 layer around the Sun would jitter at 5e7 ly).
- `sky.alpha` / `sky.near` (world.ts) control the backdrop; a later zone must not write them.
- To add a clickable galaxy: add a `GalaxySpec` row in data.ts; `registerGalactic` makes the object, hit sphere, focus angles and info panel.
